How to use harmony-py to subset ICESat-2 along-track data by variable

Author

NSIDC Data Use and Education team

Published

November 20, 2026

Problem

How do I extract a variable from an ICESat-2 along-track data set using NASA Harmony services via the harmony-py Python library?

Solution

from harmony import BBox, Client, Collection, Request
import datetime as dt

Initialize your Harmony client.

harmony_client = Client()

Define which data set you’d like to access using the collection concept-id (see how-to for retrieving collection concept-ids). For this example, we’ll use ATLAS/ICESat-2 L3A Along Track Coastal and Nearshore Bathymetry (ATL24 version 003) = C4312123631-NSIDC_CPRD.

collection = Collection(id='C4312123631-NSIDC_CPRD')

Define your spatial area of interest (here - north coast of Madagascar).

bbox = BBox(48.3,-13.6,49.1,-11.8)

Define your temporal range.

temporal = {'start': dt.datetime(2018, 12, 28),'stop': dt.datetime(2018, 12, 29)}

Define your variables of interest. We’ll retrieve the orthometric height of the photon (ortho_h), the photon classification (class_ph), and the classification confidence (confidence). We specify the variable paths within the hdf5 file.

variables = ['gt2l/ortho_h','gt2l/class_ph','gt2l/confidence']

Build the request and verify it’s valid.

request = Request(
    collection = collection,
    spatial = bbox,
    temporal = temporal,
    variables = variables
)
request.is_valid()

Submit the request. This returns a Harmony job ID that can be used to check on progress.

job_id = harmony_client.submit(request)

Discussion

NASA Harmony is comprised of cloud-based services that allow you to customize many NASA data sets, providing the ability to subset, reproject and reformat files. Not all transformation services are available for all datasets. Table of Harmony services available for select ICESat-2 data sets.
